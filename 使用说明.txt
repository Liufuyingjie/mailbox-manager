邮箱管家 · 使用说明
======================

一、启动方式
--------------------------------
双击「邮箱管家.exe」即可，就是一个独立的桌面软件，带自己的图标。
（桌面上已经放好一份，直接双击桌面上的「邮箱管家.exe」就行。）

- 不需要安装 Python，也不需要安装任何运行环境。
- 可以把这个 exe 复制到桌面、U 盘、任何文件夹，都能直接双击运行。
- 首次启动会自解压，大约 3～8 秒；之后再打开会快一些。
- 想随时打开，可以右键 exe → 发送到 → 桌面快捷方式。

二、数据存在哪 / 怎么搬走
--------------------------------
默认存放位置：
    C:\Users\<你的用户名>\AppData\Roaming\邮箱管家\data.json

便携模式（推荐给「U 盘随身带」的用法）：
    把 data.json 和 exe 放在同一个文件夹里，软件会自动改用同目录的
    data.json。这样软件和账号数据可以一起拷走，换电脑也能接着用。

提醒：exe 只有程序本身，把 exe 单独拷到别的电脑时数据不会跟着走。
要用便携模式，请连 data.json 一起拷贝。

三、导入账号（自动识别格式）
--------------------------------
每行一个账号，以下格式都能识别，并且可以混排：

  邮箱地址 密码 Client ID 刷新令牌            （空格或 Tab 分隔）
  邮箱地址----密码----Client ID----刷新令牌    （---- 分隔）
  邮箱地址----密码                          （只有地址和密码时）

例如：
  example01@outlook.com----MyPass1234
  example02@outlook.com----MyPass5678----11111111-2222-3333-4444-555555555555----M.C000_XXXX.0.ABCDEF...

导入入口：
- 「导入邮箱」→「文本导入」：直接粘贴，下方实时显示识别结果，确认后点
  「追加导入」（保留现有账号，重复邮箱自动跳过）或「覆盖导入」（先清空再导入）。
- 「导入邮箱」→「文件上传」：选择 .txt / .csv 文件，或把文件拖进上传区。

四、日常使用
--------------------------------
- 密码列右侧的眼睛图标：显示 / 隐藏密码。
- 「空闲 / 已用」：点一下即可切换，用来标记某个账号是否已经用过。
- 「正常 / 测试中」：切换账号的权限类型。
- 分组列的文件夹图标：把账号移动到其他分组（也可以在「分组管理」页新建分组）。
- 「查看」：查看账号全部信息，每项都可一键复制。
- 勾选表格左侧复选框后，可批量复制、批量设置分组、批量删除。
- 表格上方可搜索邮箱地址、按分组筛选；底部可切换每页条数和翻页。
- 右上角是作者头像，旁边的「关于我」按钮会在浏览器里打开项目仓库；点头像效果一样。

五、备份与恢复
--------------------------------
- 「导出备份」：把全部数据（含分组、已用状态）导出为一个 JSON 文件，请妥善保管。
- 恢复备份：把备份文件改名成 data.json，放到 exe 同目录或上面的默认目录即可。

六、安全提醒
--------------------------------
- 本软件完全本地运行，所有数据只保存在你的电脑上，不会上传网络。
- data.json 和导出的备份文件含有账号密码，请勿随意转发。

七、系统要求
--------------------------------
- Windows 10 / Windows 11（64 位）。
- 依赖系统自带的 Microsoft Edge WebView2 运行时，Win11 和较新的 Win10 一般已预装。
  万一提示缺失，装一次微软的「WebView2 Runtime」即可；此时软件也会自动改用
  默认浏览器打开，功能不受影响。
